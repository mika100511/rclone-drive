Datenschutzerklärung

Stand: 24. November 2026

1. Worum es geht

Diese Erklärung gilt für die private Google-Anmeldung „Rclone“. Mit ihr bindet ihr Inhaber sein eigenes Google Drive mit dem freien Programm rclone auf seinem eigenen Rechner ein. Die Anmeldung wird nur vom Inhaber selbst benutzt.

2. Auf welche Daten zugegriffen wird

Nach der Anmeldung kann rclone die Dateien und Ordner im Google Drive des angemeldeten Kontos lesen, anlegen, ändern und löschen. Das ist nötig, damit Google Drive als Laufwerk funktioniert. Andere Daten des Google-Kontos werden nicht abgefragt.

3. Wo die Daten verarbeitet werden

  • Die Daten laufen direkt zwischen dem Rechner des Nutzers und Google.
  • Es gibt keinen Server des Betreibers, über den Daten laufen oder auf dem sie gespeichert werden.
  • Der Zugangsschlüssel, den Google bei der Anmeldung ausstellt, liegt nur auf dem Rechner des Nutzers.

4. Keine Weitergabe, keine Auswertung

Daten werden nicht an Dritte weitergegeben, nicht verkauft, nicht für Werbung genutzt und nicht ausgewertet. Es werden keine Nutzungsstatistiken erhoben.

5. Google-Richtlinie

Die Nutzung von Informationen, die über Google-Schnittstellen empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).

6. Zugriff widerrufen

Der Zugriff lässt sich jederzeit im Google-Konto widerrufen, unter myaccount.google.com/permissions. Danach kann rclone nicht mehr auf Google Drive zugreifen.

7. Diese Seiten

Diese Seiten werden über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technisch nötige Daten wie die IP-Adresse. Dafür gilt die Datenschutzerklärung von GitHub. Der Betreiber selbst erhebt beim Aufruf keine Daten.
